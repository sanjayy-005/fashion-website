#  Fashion Website – KUMO Fashions

A stylish and responsive fashion website built using HTML, CSS, and JavaScript. This project showcases modern fashion collections, trending products, customer reviews, and latest fashion updates.

##  Live Demo
https://sanjayy-005.github.io/fashion-website/

##  GitHub Repository
https://github.com/sanjayy-005/fashion-website

##  Features
- Responsive navigation bar
- Fashion collection landing page
- Trending products showcase
- Product sale and new collection tags
- Product ratings and price display
- Customer reviews section
- Latest fashion updates
- Interactive Shop Now button
- Smooth scrolling navigation
- Responsive design for mobile and desktop

##  Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome

##  Responsive Design
The website is designed to work across:
- Desktop
- Tablet
- Mobile devices

##  Getting Started

### Clone the repository
```bash
git clone https://github.com/sanjayy-005/fashion-website.git
```

### Open the project
1. Navigate to the project folder.
2. Open `index.html` in your browser.
